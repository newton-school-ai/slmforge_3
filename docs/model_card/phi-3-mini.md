# Phi-3 Mini

## Model Information

- **Model Name:** Phi-3 Mini
- **Hugging Face ID:** `microsoft/Phi-3-mini-4k-instruct`
- **Default LoRA Recipe:** `qlora`
- **Recommended VRAM:** 8 GB
- **License:** MIT

## Recommended Tasks

- Chat
- Classification
- Instruction Following
- Question Answering
- Summarisation

## Notes

Phi-3 Mini is a lightweight instruction-tuned language model suitable for
resource-constrained environments. It offers strong reasoning capability while
remaining efficient enough for consumer GPUs.
